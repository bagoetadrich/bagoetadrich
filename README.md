## 👤 About Me

I'm **Aldrich (MmzMing)**, a 20-year-old developer who started with frontend and taught myself UE5, Java, Python, and AI over two years — all while working part-time jobs and coding in internet cafes.

Today I lead a 5-person team building **WeiMing**, an AI emotion engine that gives virtual beings memory, feelings, and autonomous behavior.

- 🔭 **Current mission**: Integrate the prototype by Aug 15.
- 🧠 **Core focus**: Layered memory (working/episodic/core) + Ebbinghaus forgetting curve + GNN-driven actions.
- 🚀 **Next horizon**: Porting the engine to physical robots (hardware-agnostic design).
- 💬 **Ask me about**: Full-stack architecture, AI engineering, Unreal Engine, or the reality of bootstrapping a project.
- ⚡ **Fun fact**: I built the entire backend, client, and action pipeline myself before expanding the team.

## 🚀 Featured Project: WeiMing AI Emotion Engine

> *An AI that remembers, forgets, and feels — not just a chatbot.*

| Component | Description |
|-----------|-------------|
| **Memory System** | Three-tier memory (working, episodic, core) with Ebbinghaus decay, vector retrieval (cosine), and sudden recall. |
| **Emotion Engine** | Real-time analysis of user input (text + speech prosody), affecting 5D emotion vector (T/D/A/C/AV). |
| **Action Engine** | GNN-based model (PyTorch → ONNX) that generates morph/bone parameters from emotion and behavior tags — no preset animations. |
| **Architecture** | UE5 client + Java Spring Boot backend + Python FastAPI action server + MySQL (shared). |
| **Proactive Mode** | Timed LLM calls + WebSocket push when the user is silent. |
| **Story System** | Node-based narrative with trigger conditions, generating auxiliary prompts for the LLM. |
